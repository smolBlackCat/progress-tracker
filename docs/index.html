Progress

Simple kanban board manager for Linux

About Progress

Progress is a Kanban board management app designed to be simple yet flexible for most workflows. Whether you're managing software projects or organising daily tasks, Progress keeps things straightforward. Built with C++ with GTK4 and libadwaita.
